# CAT 2: PHP Web Application (CNS 3205 Server Administration)
Signup, login and feedback pages in PHP, backed by MariaDB on Apache.
- Copy `config.sample.php` to `config.php` and set the real DB password (never commit it).
- Run the files in `sql/` in order to build the CAT2 database.
- `.github/workflows/serverless-demo.yml` illustrates serverless compute (Part A Q3).
